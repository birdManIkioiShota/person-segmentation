# 人物セグメンテーション

SAM 2.1を用いて、画像に写った人物の領域を抽出し、背景が透明なPNG画像を生成するPythonスクリプトです。元画像のファイル名と画像サイズを維持します。PNG以外のファイルは変更せずコピーするため、画像に付随するアノテーションファイルも同じディレクトリ構成で出力できます。

## 前提条件

- 入力PNG画像には、画像中央付近に人物が1人だけ写っていることを想定しています。
- 人物の指定には画像の中心点を使用します。中心点が背景にある画像や人物の輪郭が複雑な画像では、意図した領域を抽出できない場合があります。
- 切り抜き結果の品質は利用者が目視確認します。自動的な品質保証やマスクの手動編集機能はありません。

## 動作環境

- Python 3.12
- CUDA対応GPUおよび対応するNVIDIAドライバー
- [uv](https://docs.astral.sh/uv/)

PyTorchおよびTorchVisionはCUDA 12.8向けの配布パッケージを使用します。SAM 2.1 Largeのモデル重みは公開配布されており、利用申請やHugging Faceへのログインは不要です。

## セットアップ

リポジトリをクローンした後、依存関係をインストールしてください。SAM 2の追加CUDA拡張は不要なため、ビルドを無効化します。

```bash
SAM2_BUILD_CUDA=0 uv sync
```

初回のPNG処理時に、SAM 2.1 Largeのモデル重みを公式配布先から自動ダウンロードし、`~/.cache/person-segmentation/` に保存します。以降は保存済みの重みを使用します。

## 実行方法

入力元と出力先のディレクトリを指定して実行します。

```bash
uv run python segment.py --input ./input --output ./output
```

`--input` と `--output` は必須です。入力元と出力先には、同じディレクトリや包含関係にあるディレクトリを指定できません。

## 入出力

スクリプトは入力ディレクトリ内のファイルを再帰的に処理し、元の相対パスを維持して出力します。処理結果の構成例を以下に示します。

入力:

```text
input/
├── 0001.png
├── 0002.png
├── labels.csv
└── gt/
    └── poses.json
```

出力:

```text
output/
├── 0001.png
├── 0002.png
├── labels.csv
└── gt/
    └── poses.json
```

PNG画像は人物領域にAlphaチャンネルを付けてRGBA形式で保存します。中心点を人物に属する点としてSAM 2.1に指定し、生成された候補マスクのうち前景画素数（面積）が最も多いものを使用します。候補に人物全体のマスクが含まれない場合、髪や服などを含む全身の切り抜きは保証されません。輪郭には軽いぼかしを適用します。元画像のRGB値は変更しません。

PNG以外のファイルは内容を変更せずコピーします。出力先に同名のファイルが存在する場合は、PNGもその他のファイルも上書きします。空のサブディレクトリはコピーしません。処理中はtqdmでファイル全体の進捗を表示し、PNG変換とその他のファイルのコピーを進捗に含めます。

## エラー処理

入力ディレクトリが存在しない場合やCUDAが利用できない場合、処理を開始せずエラー終了します。個別画像の処理やファイルコピーに失敗した場合は対象ファイルのエラーを表示し、残りのファイルの処理を続行します。

処理終了時に成功・コピー・スキップ・失敗件数を表示します。失敗が1件以上発生した場合は、終了コード1を返します。生成された切り抜き画像は目視で確認してください。
