# 人物セグメンテーションと背景合成プレビュー

SAM 2.1を用いて、画像中央付近の単一人物を切り抜くPythonスクリプトです。背景を透過したPNGの生成と、室内背景との合成結果のプレビュー生成に対応します。後者は合成結果の目視確認を目的とし、学習時のオンラインデータ拡張は実装しません。

## 動作環境

- Python 3.12、[uv](https://docs.astral.sh/uv/)
- CUDA対応GPUおよび対応するNVIDIAドライバー

PyTorchとTorchVisionはCUDA 12.8用のパッケージを利用します。人物切り抜きに使うSAM 2.1 Largeの重みは、初回実行時にMetaの公開配布先から取得します。モデル利用申請は不要です。

依存関係をインストールするコマンドは次のとおりです。SAM 2の任意のCUDA拡張はビルドしません。

```bash
SAM2_BUILD_CUDA=0 uv sync
```

## 人物切り抜き

入力ディレクトリ以下のPNGを人物だけが残るRGBA PNGへ変換します。PNG以外のファイルはバイト列を変更せずコピーします。いずれも元の相対パス・ファイル名を維持し、既存の出力ファイルがあれば上書きします。

```bash
uv run python segment.py --input ./input --output ./output
```

人物領域は画像中心の1点をプロンプトにSAM 2.1で推定し、候補の中から面積最大のマスクを採用します。マスク境界に弱いぼかしを加え、元のRGB画像にAlphaチャンネルを付加します。中心点が人物以外に重なる場合や、モデルの候補に髪・服などが含まれない場合は切り抜きに失敗することがあります。

## 背景合成プレビュー

入力ディレクトリ以下のPNGについて、各画像を一度だけ人物切り抜きし、ランダムな室内背景のランダムな領域と合成して10枚ずつRGB PNGとして保存します。人物の位置・大きさ・姿勢は変更しません。PNG以外のファイルはプレビュー出力先へコピーしません。

```bash
uv run python preview_backgrounds.py \
    --input ./input \
    --backgrounds ./backgrounds \
    --output ./preview \
    --samples 10
```

`--samples`は入力PNG1枚あたりの出力数で、省略時は10です。合成画像の名前は元画像の拡張子の直前に生成番号を付けたものになります。元画像のファイル名に含まれるアノテーション情報は変更しません。サブディレクトリ構成も維持します。

例えば、`input/sub/yaw_135_pitch_010.png`からは`preview/sub/yaw_135_pitch_010_00.png`〜`preview/sub/yaw_135_pitch_010_09.png`が生成されます。既存のプレビュー画像は上書きします。

背景は元画像の縦横比に合わせてランダムクロップしてからリサイズし、人物のAlphaチャンネルで合成します。背景HDRIの正距円筒図法を通常の矩形クロップで使用するため、遠近の歪みが残る場合があります。プレビュー画像は外観を目視確認してください。

## 背景データの自動取得

背景は[Poly Haven](https://polyhaven.com/)がCC0で公開する室内HDRIを使用します。アセットの商用利用は可能です。アセットのライセンスとAPI利用条件はそれぞれ[公式ライセンス](https://polyhaven.com/license)と[公開APIの利用規約](https://github.com/Poly-Haven/Public-API/blob/master/ToS.md)を参照してください。

プレビュー生成時、`--backgrounds`の保存先に背景ファイルがなければ公式APIから自動取得します。初回は公開済みの室内HDRIからアセットIDを辞書順に最大200件選び、`backgrounds/asset_ids.json`に保存します。以降の実行ではこの一覧を使用し、不足しているファイルだけをダウンロードします。全件を取得し直すには保存先ディレクトリを別途指定してください。取得先のアセット構成が更新された場合、初回取得時期によって選ばれるIDが変わる場合があります。

各アセットのトーンマッピング済みJPGを取得し、配布元が提供するMD5で検証した後、横幅を最大2048ピクセルに縮小して保存します。必要な画像は自動取得されるため、別の準備コマンドやアーカイブ展開は不要です。初回は最大200件の画像取得が発生するため、データ通信量と所要時間が増えます。対象数・保存解像度は`background_assets.json`で設定します。

本スクリプトはPoly Havenの公式APIを使用し、識別可能なUser-Agentを送信します。背景データの提供元は**Poly Haven（CC0）**です。アセット自体の著作者表示はライセンス上必須ではありませんが、APIを利用するソフトウェアには提供元の表示が求められます。

## エラー処理

入出力ディレクトリの重複や不正な引数はエラーとして終了します。背景取得に失敗した場合、プレビュー生成は開始しません。人物切り抜き・コピー・画像保存の個別失敗は表示し、他の入力画像の処理を続行します。tqdmで進捗を表示し、失敗があれば終了コード1を返します。
