# 人物セグメンテーション

SAM 3を使用して画像中央の単一人物を背景透過PNGとして保存するスクリプトです。CGマネキンをリアル化した人物画像を対象とし、切り抜き結果の品質確認は人手で行います。背景画像の合成機能は含みません。

## 動作環境

- Python 3.12
- CUDA対応GPU（SAM 3公式要件はCUDA 12.6以上、PyTorch 2.7以上）
- [uv](https://docs.astral.sh/uv/)
- [SAM 3のモデル使用承認](https://huggingface.co/facebook/sam3)とHugging Faceへのログイン

依存関係にはCUDA 12.8向けのPyTorchを指定しています。SAM 3はGitHubの特定コミットに固定しています。

## セットアップ

```bash
uv sync
uv run hf auth login
```

初回実行時にはSAM 3の重みがダウンロードされます。Hugging Face側で事前にモデルの使用申請を済ませてください。

## 実行

```bash
uv run python segment.py --input ./input --output ./output
```

`--input` と `--output` は必須です。入力ディレクトリ直下およびそのサブディレクトリにあるファイルを対象とします。入出力ディレクトリは重複しない場所にしてください。

### 入出力例

入力:

```text
input/
├── 0001.png
├── 0002.png
├── labels.csv
└── gt/
    └── poses.json
```

出力:

```text
output/
├── 0001.png
├── 0002.png
├── labels.csv
└── gt/
    └── poses.json
```

PNGは元画像と同じファイル名・画像サイズの**RGBA画像**として保存します。人物のRGB値を維持し、SAM 3が推定した人物マスクをAlphaチャンネルに使用します。複数の人物候補が出た場合は最高スコアの候補を採用します。

**PNG以外のファイルは内容を変更せずコピー**します。サブディレクトリがある場合は相対パスも維持します。空ディレクトリはコピーしません。既存の出力ファイルは上書きせずスキップします。

人物が検出されないPNGや読み込みに失敗したファイルはスキップしてエラーを表示します。最後に処理件数を表示し、失敗があれば終了コード1を返します。

出力された人物マスクの品質は人手で確認してください。SAM 3の人物マスクは、髪の毛や輪郭が完全に保持されることを保証するものではありません。
